相關討論:
Superpowers 是專門給「coding agent」用的 plugin/skills 框架，目前支援的是 Claude Code、Codex、Cursor、OpenCode、Copilot、Gemini CLI 這類命令列或 IDE 裡的編程代理，不是 Claude.ai 的網頁聊天介面。 [ClaudePluginHub](https://www.claudepluginhub.com/plugins/obra-superpowers-2)

也就是說：

- **Claude Code（終端機裡那個）** ✅ 可以用，用 `/plugin install superpowers@claude-plugins-official` 就能裝，brainstorming skill 會在你描述要做的功能時自動觸發。 [Builder.io](https://www.builder.io/blog/claude-code-superpowers-plugin)
- **Claude.ai 的 chat（你現在用的這個）** ❌ 不能裝 plugin，所以沒辦法直接用 Superpowers 的 brainstorming skill。

不過如果你想要的是「那種會先反問釐清需求、再提出 2-3 種方案、最後產出設計文件」的體驗，Superpowers 的 brainstorming 流程其實就是：探索專案脈絡 → 一次問一個釐清問題（盡量用選擇題） → 提出 2-3 種做法 → 分段呈現設計 → 寫成 spec 文件。 [ClaudePluginHub](https://www.claudepluginhub.com/skills/obra-superpowers-2/brainstorming)
