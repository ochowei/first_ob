# Claude Skill Social Post

## Raw Capture

https://www.facebook.com/share/p/1E7rogXs1m/

我昨天打開後台看，是 29 萬瀏覽。今天再看，35 萬。

一天就多了 6 萬。

一直在燒的那篇，是用一個 open source 的「爆款貼文公式」寫的。那套公式是一位叫 Hao 的開發者整套公開在 GitHub 的，東西很強。

但我沒照它的範例走。它的範例風格我實在受不了，滿滿的「殺瘋了」「不看後悔」「不轉可惜」，我這種做設計的看了渾身不對勁。

後來我才發現一件事：那個 hype 的語氣，其實不是寫死在公式裡的。你完全可以叫 AI 用你自己的口氣，去改它生出來的句子。

我也沒做什麼了不起的事，就是請它別那麼浮誇，照我平常講話的樣子重寫。骨架是它的，講話的方式是我的。

結果它就這樣一天一天往上加，我看著數字到現在還有點消化不來。

所以如果你也怕「AI 寫出來都很油、很不像自己」，其實不用怕。公式可以借，語氣請 AI 換成你的就好。

連結放這裡（免費、open source）：
