4.[小遊戲三]第三個計畫, "請深入分析這個 LPMUD(MUDLIB folder path)

ChatGPT 讀 README 寫的介紹文:

 ![📌](https://static.xx.fbcdn.net/images/emoji.php/v9/t4b/2/16/1f4cc.png) 我如何利用 Claude Code、四個 Prompt 與一套免費素材，生成 MMORPG《TinyRealms Online》

許多人以為開發一款 MMORPG，必須要有數十人的團隊、數年的開發週期，以及龐大的預算才能完成。

但《TinyRealms Online》的誕生，來自一個有趣的實驗：  
![👉](https://static.xx.fbcdn.net/images/emoji.php/v9/tf0/2/16/1f449.png) **如果給 AI 一個極小的 Java 遊戲引擎、一套免費像素素材，以及一個經過數十年驗證的 MUDLIB，AI 是否能夠一步一步把它演化成一款真正可玩的 MMORPG？**

答案是：可以，而且過程遠比想像中有趣。

 ![🧱](https://static.xx.fbcdn.net/images/emoji.php/v9/t3b/2/16/1f9f1.png) 我提供給 Claude Code 的三個「積木」

 ![1️⃣](https://static.xx.fbcdn.net/images/emoji.php/v9/t59/2/16/31_20e3.png) Map Engine（不到 100KB 的 Java Tile Engine）

它本身並不是 MMORPG 引擎，甚至沒有任務、網路、職業、怪物與經濟系統。它只具備：Tile 地圖、角色移動、碰撞判定與基本渲染。但它提供了一個最重要的基礎——**「一個可互動的世界」**。

 ![2️⃣](https://static.xx.fbcdn.net/images/emoji.php/v9/t78/2/16/32_20e3.png) Tiny Swords Free Pack（免費像素素材包）

包含地圖 Tile、建築、NPC、武器與怪物。這些素材讓 AI 能快速、具體地理解：這個圖形世界應該長什麼樣子。

 ![3️⃣](https://static.xx.fbcdn.net/images/emoji.php/v9/t97/2/16/33_20e3.png) ES 東方故事 MUDLIB（真正的核心靈魂）

這是一個經過多年驗證的 LPMUD 程式庫。它包含了世界觀、職業、武功、升級、經濟、公會、生死機制與戰鬥系統。某種程度上，它已經是一份完整的 MMORPG 設計藍圖，只是原本存在於文字世界。**而我的目標，就是把它「轉譯」成圖形化 MMORPG。**

 ![🚀](https://static.xx.fbcdn.net/images/emoji.php/v9/t65/2/16/1f680.png) 核心實戰：讓 AI 遞進演化的 4 個關鍵 Prompt

 ![💡](https://static.xx.fbcdn.net/images/emoji.php/v9/tdb/2/16/1f4a1.png) Prompt 1：分析引擎，建立系統理解

- **指令核心**：`Analyze this folder. Inspect architecture. Explain rendering pipeline, map loading, entity system, and extension points. Write a detailed technical report before coding.`
    

- **為什麼重要**：很多人一開始就盲目要求 AI「幫我做 MMORPG」，結果 AI 根本不知道手上的引擎能做什麼。這一步是先讓 AI 成為「引擎維護者」，而不是單純的程式碼生成器。
    

 ![💡](https://static.xx.fbcdn.net/images/emoji.php/v9/tdb/2/16/1f4a1.png) Prompt 2：先做一個小遊戲，建立工作模式

- **指令核心**：`Write a complete small RPG using the existing engine and Tiny Swords assets. Design NPC, Monsters, Combat, Score/Level System, and Boss Battle. Provide complete implementation plan before coding.`
    

- **為什麼重要**：這步的目的不是做最終產品，而是建立「引擎 × 素材」的工作流。AI 開始理解 Tile 如何使用、Sprite 如何組裝、UI 如何呈現，第一個可玩的單機 RPG 於是誕生。
    

 ![💡](https://static.xx.fbcdn.net/images/emoji.php/v9/tdb/2/16/1f4a1.png) Prompt 3：擴大成 ARPG，注入遊戲深度

- **指令核心**：請規劃一個更宏大、具備成長性、黏著度、打寶、升級、Boss、副本、多區域探索與技能樹的裝備系統。請先完成完整的 GDD（遊戲設計文件）。
    

- **為什麼重要**：這是一個重要轉折點。AI 不再思考基礎的「如何顯示角色」，而開始思考商業層面的「如何讓玩家玩 100 小時」（Loop / Progression / Retention）。
    

 ![💡](https://static.xx.fbcdn.net/images/emoji.php/v9/tdb/2/16/1f4a1.png) Prompt 4：翻譯 MUDLIB，進行知識轉譯

- **指令核心**：深入分析 LPMUD MUDLIB 的世界觀、職業與生死機制。
    

- _Rooms ➔ Services / Dynamic Maps_
    

- _Channels ➔ Modern Chat_
    

- _Guilds & Combat ➔ Real-Time System_
    

- _Use multiple design agents: Extract, Analyze, Design first, Implementation later._
    

- **為什麼重要**：這一步本質上是「知識轉譯」。AI 需要將原本文字世界的「房間」翻譯成「地圖區域」；文字的「頻道聊天」變成「世界與公會頻道」；「文字戰鬥」全面轉譯為「即時戰鬥、技能特效、AOE、擊退與無敵幀」。
    

最後，Claude Code 不再是在寫一個遊戲，而是在重建一個世界。

 ![🌌](https://static.xx.fbcdn.net/images/emoji.php/v9/t5d/2/16/1f30c.png) TinyRealms Online 的誕生與啟示

當這四個 Prompt 串接起來後，有趣的現象出現了：  
AI 並不是凭空從零設計 MMORPG，而是在進行 **Engine + Art + Mudlib + Prompt Engineering** 的終極融合。

最終形成的《TinyRealms Online》，完美保留了東方故事 MUD 的靈魂，卻以現代像素 MMORPG 的圖形形式呈現。

這或許也是 AI 時代遊戲開發最迷人的地方：  
**我們不再只是埋頭寫程式，而是在擔任導師，教 AI 如何去理解、翻譯並重組人類數十年來累積下來的遊戲設計智慧。**
