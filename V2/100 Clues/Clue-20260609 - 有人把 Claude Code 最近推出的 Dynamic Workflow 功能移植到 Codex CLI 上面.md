有人把 Claude Code 最近推出的 Dynamic Workflow 功能移植到 Codex CLI 上面，用「技能」＋「開源」的方式釋出，名叫 codex-dynamic-workflows，你只要一個提示詞就可以安裝好，怕貴可以自己敲指令裝。 ![🎁](https://static.xx.fbcdn.net/images/emoji.php/v9/t23/2/16/1f381.png)

我昨天是直接用在 Copilot CLI 裡面用，跑的超好，我有兩個 .NET 專案都是一個提示詞就順利改寫成 Rust 版本。他真的可以幫我動態拆解任務後，規劃大量子代理去實作，真的很有潛力！我認為 OpenAI 之後也會自己做一套！![✊](https://static.xx.fbcdn.net/images/emoji.php/v9/te0/2/16/270a.png)

我猜大部分 GitHub Copilot 訂戶現在都不敢玩這些好東西了，其實軟體工程師的差距，大概會從「現在」開始加劇。各位不要小看待在企業上班的工程師，人數非常多，而且大部分人都不可能花錢訂閱 AI 方案，公司不給就寧願不用。我大概知道之後面試要問些什麼問題了！![😅](https://static.xx.fbcdn.net/images/emoji.php/v9/tf2/2/16/1f605.png)
