# 網友分享的 AI 繪圖工具

## Raw Capture

https://github.com/boona13/image-extender

獨立開發者有福了
Image Extender 是一個開源 AI 工具，專為 2D 遊戲美術設計。用 AI 往外延伸圖片，風格、顏色、接縫完全一致，拿來做 tileset、背景、角色 sprites、整組遊戲素材包都行。
以前拉一張圖，接縫明顯、顏色跑掉、手動 PS 修到崩潰，不同素材之間風格還不一致。這個工具可以直接解決這些麻煩。
目前 GitHub 64 stars，還很早，但以我的測試結果來看已經很實用。如果你在做像素遊戲或 2D 遊戲，可以研究看看。
