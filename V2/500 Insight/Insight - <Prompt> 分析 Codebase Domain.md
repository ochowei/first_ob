# 分析 Codebase Domain

## TL;DR / Summary

用 1-2 句話精煉這個洞察的核心結論。


```
「請分析這個 repo,列出你觀察到的主要 domain(例如 auth、billing、notification、user-profile...)。針對每個 domain 告訴我:1) 相關的目錄/檔案 2) 估計的複雜度 3) 是否有明顯的對外 API 或行為介面。先不要寫 spec。」
```
